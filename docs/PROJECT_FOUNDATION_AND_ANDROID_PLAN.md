# Edu Mini — Offline AI Learning Studio

## وثيقة تأسيس وتصميم التطبيق

**Version:** 1.0  
**Date:** 2026-11-23  
**Target repository:** ameryhusam/mini_edu  
**Architecture:** Android-first · Offline-first · AI-assisted content authoring

> ai_books تطبيق مستقل لإعداد المحتوى التعليمي وإدارته محلياً، ويملك دورة الفهرسة والتقطيع والتصدير والاستيراد بالكامل. لا يوجد اعتماد تشغيلي أو برمجي على Indexer2.

## 1. الرؤية

إنشاء تطبيق Android لإدارة المحتوى من جهاز الوالد/المعلم: استيراد PDF مؤقتاً، استخراج الفهرس ومراجعته، تقطيع الدروس، إعداد الشروح والأسئلة والاختبارات، ثم تصدير حزمة ZIP مستقلة لكل صف إلى أجهزة الأبناء. تستورد أجهزة iPad الحزمة وتعرض ملفات الدروس محلياً دون اتصال. يسجل كل جهاز تقدم الطفل ودرجاته محلياً، ويمكن مزامنتها لاحقاً مع خدمة online موثوقة لعرض تقارير الوالد. AI عبر API يحتاج اتصالاً؛ أما المحتوى المستورد والتعلم فيعملان Offline.

## 2. التقنية المقترحة

- React Native + TypeScript لتطبيق Android.
- Expo مع native modules عند الحاجة، وEAS أو Android build محلي.
- SQLite للبيانات الوصفية والعلاقات.
- Android Storage Access Framework لاستيراد الملفات.
- PDF viewer مناسب للأندرويد.
- PDF text extraction محلي، وOCR عند الحاجة.
- AI provider adapter قابل للتبديل.
- JSON Schema / runtime validators لمخرجات AI.
- React components لتشغيل أنشطة تفاعلية من بيانات JSON آمنة.
- ZIP + JSON + manifest لتبادل مساحة العمل.
- SHA-256 للتحقق من سلامة الملفات.
- Android secure storage لمفاتيح المستخدم.

Python ليس الخيار المفضل لبناء واجهة Android؛ يمكن إضافته لاحقاً لخدمة OCR أو معالجة المستندات الثقيلة.

## 3. بنية التنقل

الرئيسية، الصفوف، المواد، الكتب، الوحدات، الدروس، مساحة العمل، AI Studio، بنك الأسئلة، التقييمات، النسخ الاحتياطي/الاستيراد والتصدير، الإعدادات.

## 4. عزل الصفوف

كل كتاب ومادة ووحدة ودرس ومساحة عمل وسؤال وتقييم ومهمة AI مرتبط بصف عبر معرفات ثابتة. اختيار الصف يعرض بياناته فقط. عمليات الاستيراد تتحقق من الصف والعلاقات قبل الدمج.

## 5. رفع PDF وتقسيمه

1. اختيار PDF من منتقي الملفات.
2. استخدام ملف المصدر مؤقتاً للاستخراج والتقطيع والتحقق؛ لا يُحتفظ بنسخة PDF الأصلية داخل التطبيق بعد اكتمال دورة العمل بنجاح. ملفات PDF المشتقة للدروس تبقى في Workspace.
3. حساب SHA-256 وحفظ metadata وعدد الصفحات.
4. استخراج النص لكل صفحة واكتشاف قابلية استخراج النص أو الحاجة OCR.
5. تحديد الفهرس والعناوين وأنماط الوحدات والدروس.
6. اقتراح حدود الدروس باستخدام قواعد وفهرس وتحليل AI.
7. معاينة التقسيم وتعديل العناوين وبداية/نهاية الصفحات.
8. اعتماد التقسيم وإنشاء سجلات الدروس ومساحة العمل.

لا يعتمد تقسيم الصفحات على AI وحده. تُدمج قراءة الفهرس، واكتشاف العناوين، وترقيم الصفحات، وتحليل النص. يسمح بالتقسيم اليدوي عند ضعف OCR. يحتفظ التطبيق بالكتاب الأصلي مرة واحدة، ويولّد PDF مجزأ عند الطلب لتقليل تكرار التخزين.

## 6. مساحة العمل

لكل كتاب Workspace ولكل درس محتوى مستقل: مصدر الدرس وصفحات المصدر، شرح، ملخص، أهداف تعلم، مفردات، أمثلة محلولة، نشاط تفاعلي، بنك أسئلة، تقييمات مرتبطة، ملاحظات المعلم، سجل AI، وحالة المراجعة/الإصدار.

كل عنصر يحفظ معرف الدرس والمصدر والصفحات، ونوع المحتوى، وأصل الإنشاء (يدوي/AI)، وتاريخ الإنشاء والتحديث، والإصدار، وحالة المراجعة. مخرجات AI تبقى مسودة ولا تعتمد تلقائياً.

## 7. AI Task Engine

محرك موحد للمهام: بناء سياق الصف/المادة/الكتاب/الدرس/الصفحات، اختيار قالب ومخطط مخرجات، تنفيذ الطلب عبر provider adapter، التحقق من JSON والحقول والإجابات والارتباط بالمصدر والتكرار، حفظ المسودة، عرضها للتحرير والمراجعة، ثم اعتمادها أو رفضها. تحفظ حالات الفشل وتدعم retry دون فقد تعديلات المستخدم.

القوالب الأولية: lesson_explainer، lesson_summary، learning_objectives، vocabulary_builder، worked_examples، interactive_activity، mcq_generator، true_false_generator، fill_blank_generator، short_answer_generator، assessment_builder، lesson_review، difficulty_adapter.

دعم مزود ونموذج قابلين للتبديل. مفاتيح API الموجودة داخل APK يمكن استخراجها؛ مفاتيح المستخدم الشخصية تُحفظ في Android secure storage مع توضيح المخاطر. عند التوزيع أو استخدام مفاتيح مشتركة، يجب نقل AI إلى Backend آمن، ولا تُضمّن أسراراً مشتركة داخل APK.

## 8. بنك الأسئلة

أنواع الإصدار الأول: اختيار متعدد، صح/خطأ، إكمال، إجابة قصيرة، ترتيب، توصيل، سؤال بصورة، سؤال مرتبط بصفحة مصدر.

بيانات السؤال: ID ثابت، الصف والمادة والكتاب والوحدة والدرس، النوع والنص والسياق، الخيارات والإجابة والتفسير، الصعوبة والدرجة وهدف التعلم، صفحات المصدر والوسائط، حالة المراجعة، fingerprint/version.

وظائف: توليد دفعي، اختيار العدد والنوع والصعوبة، تحرير وحذف وبحث وتصفية، كشف التكرار، ربط المصدر، تصدير. كشف التكرار يعرض تحذيراً ولا يحذف تلقائياً.

## 9. التقييمات

أنواع: قبلي، تكويني، قصير، شامل، نهائي، ذاتي. خصائص: الاسم، الصف، المادة، الكتاب، الوحدة والدروس، الأسئلة وترتيبها، الدرجات، الزمن، الصعوبة، النجاح، الحالة. تُحفظ نتائج المتعلم محلياً منذ البداية، ويجب أن تكون هوية كل متعلم مستقلة. يدعم التصميم توزيع المحتوى من جهاز الإدارة إلى أجهزة الطلاب، ومزامنة الأداء لاحقاً أو عند توفر الاتصال دون جعل الاتصال شرطاً للتعلم.

## 10. الأنشطة التفاعلية

قوالب آمنة: Quiz، Flashcards، Matching، Ordering، Fill Blank، Drag/Drop، Image Hotspot، Step Activity، Simple Simulation، Reading Activity. AI ينتج بيانات JSON للقالب، وليس سكربتات غير محدودة. تحفظ الأنشطة بإصدارات وتعرض عبر React components لدعم Offline. أي WebView محتمل يكون محدود الصلاحيات ومعزولاً.

## 11. Offline والتخزين

SQLite للبيانات، ونظام الملفات للـPDF والوسائط. لا تخزن PDFs كبيرة داخل SQLite. وظائف Offline: الصفوف والكتب وPDF والتقسيم والدروس ومساحة العمل والأسئلة والتقييمات والأنشطة والنسخ الاحتياطي والاستيراد والتصدير. AI API يحتاج اتصالاً؛ تحفظ المهام والمسودات لإعادة المحاولة.

تنظيم الملفات: Workspace إداري محلي بهيكل الكتاب/الوحدات/الدروس، مع ملفات PDF المشتقة وملفات HTML والموارد. يصدر التطبيق حزمة `grade-package.zip` لكل صف تتضمن ملفات الدروس وبيانات الربط الأساسية ومعرفات ثابتة ومسارات نسبية وبصمات SHA-256 وmanifest. لا تتضمن الحزمة قاعدة بيانات الإدارة كاملة أو أسرار AI أو بيانات أداء الطلاب. تستورد أجهزة الطلاب الحزمة إلى تخزين محلي يديره التطبيق.

## 12. جداول SQLite

grades، subjects، books، units، lessons، lesson_sources، workspaces، lesson_contents، interactive_activities، questions، question_options، assessments، assessment_items، ai_tasks، ai_outputs، assets، review_events، settings، import_jobs، export_jobs.

استخدم UUIDs لهويات الكيانات. Fingerprints للكشف عن التكرار وليست بديلاً للمعرفات. يجب وضع سياسة normalization عربية محافظة؛ لا تُحذف الهمزة أو التشكيل أو تعدّل الحروف العربية دون سياسة معتمدة.

## 13. Workspace import/export

صيغة التوزيع `grade-package.zip` تشمل metadata الصف والكتب والوحدات والدروس، ملفات PDF المشتقة للدروس، موارد HTML/interactive، وأي أسئلة/تقييمات منشورة للطالب، مع stable IDs ومسارات نسبية وmanifest وإصدار وبصمات. لا تشمل PDF المصدر الأصلي ولا قاعدة بيانات الإدارة ولا سجل أداء المتعلم.

الاستيراد يتحقق من ZIP path traversal، schema، version، hashes، الصف المستهدف، التكرار والمعرفات؛ يعرض معاينة ويتيح merge أو replace. لا يستبدل محتوى دون تأكيد. يحفظ backup قبل replace ويبلغ عن الفشل الجزئي دون إتلاف بيانات سابقة.

التصدير يدعم الصف، الكتاب، الدرس، مساحة العمل، بنك الأسئلة، والتقييم.

## 14. UX والهوية

**قيد منصة مهم:** المستودع الحالي تطبيق Android أصلي مبني بـ Kotlin وJetpack Compose وGradle (`com.android.application`) ولا يحتوي مشروع iOS/Xcode. لذلك APK الحالي لا يمكن تثبيته على iPadOS. عقد حزمة الصف وملفات PDF يمكن جعلهما مشتركين بين Android وiPad، لكن تشغيله على iPad يتطلب تطبيق iPadOS منفصلاً/نقلاً إلى بنية متعددة المنصات أو قراراً باستخدام أجهزة Android للأبناء. لا تُسجل ميزة iPad على أنها مدعومة قبل وجود build واختبارات فعلية على iPadOS.

Mobile-first مع دعم Tablet، Arabic RTL من البداية، ألوان Indigo/Blue مع Teal/Green، خلفيات محايدة، تسلسل واضح، بطاقات، تقدم، وتقليل ازدحام الواجهات. Home تعرض الصفوف/الكتب/الدروس/مسودات AI ومتابعة آخر مساحة عمل. Workspace يربط مصدر PDF بالمحرر؛ على Tablet يمكن split-view وعلى الهاتف أقسام أو tabs.

## 15. الأمن والاعتمادية

حماية مفاتيح المستخدم، عدم تضمين أسرار مشتركة، اعتبار الملفات المستوردة ومخرجات AI غير موثوقة، تقييد الأنشطة، التحقق من JSON وZIP paths، IDs وhashes ثابتة، حفظ التحرير قبل AI، retry/cancel، عدم حذف الأصل، backup قبل الاستبدال، إظهار حالة المهام والفشل، وعدم تسجيل المفاتيح.

## 16. توافق indexer2

Edu Mini مستقل في الإصدار الأول، مع قابلية التبادل: UUIDs، lesson/question IDs، schemas، أنواع الأسئلة والأنشطة، أهداف التعلم، مصادر وصفحات، review metadata، assets، hashes، manifest وformat version. التدرج: Offline مستقل، export/import متوافق، اختبار توافق schema، sync اختياري، اعتماد المحتوى في Backend، ثم نشره لتطبيق الطالب.

## 17. مراحل التنفيذ

**P01 Foundation:** إعداد Android/TypeScript/navigation/RTL/SQLite/filesystem.

**P02 Grades & Books:** الصفوف والمواد والمكتبة وPDF import/viewer.

**P03 PDF Intelligence:** استخراج النص، تحليل الفهرس، اكتشاف OCR، اقتراح التقسيم ومحرر الحدود.

**P04 Workspace:** محرر الدرس، المصدر، الشرح، الملخص، الأهداف، الأمثلة والوسائط.

**P05 AI Studio:** providers، القوالب، task queue، validation، retry، مراجعة المسودات.

**P06 Question Bank:** الأسئلة اليدوية والمولدة، التحرير، التصفية، كشف التكرار، المصدر.

**P07 Assessments:** بناء التقييم، اختيار الأسئلة، الدرجات، الزمن، المعاينة والتصدير.

**P08 Offline & Transfer:** ZIP import/export، backup/restore، integrity، recovery.

**P09 QA & APK:** الاختبارات، الأداء، فحص الأجهزة، بناء APK والتحقق من التثبيت.

## 18. تقدير الزمن

- Prototype: 3–5 أيام.
- MVP أولي: 12–18 يوم عمل.
- نسخة شخصية مستقرة: 3–5 أسابيع.
- نسخة مصقولة: 5–8 أسابيع.
- OCR متقدم: 1–3 أسابيع إضافية حسب نطاقه وجودة الكتب والأجهزة.

هذه تقديرات وليست ضماناً؛ الحالات المعقدة للPDF، الكتب المصورة، OCR، توافق الأجهزة، والاستعادة قد تمدد الوقت. الهدف العملي هو إصدار قابل للاستخدام خلال 3–4 أسابيع مع نسخة أولية مبكرة للاختبار.

## 20. مؤجل عن MVP

إدارة المدارس متعددة المؤسسات، التحليلات المتقدمة، الأنشطة الجماعية، الألعاب المعقدة، LLM محلي داخل الهاتف. أما هوية الطالب ومزامنة الأداء الأساسية فهما جزء من مسار المنتج المستهدف، ويمكن تفعيل المزامنة تدريجياً بعد استقرار الحفظ المحلي وحزمة الصف.

## 21. تعريف النجاح

يستطيع الوالد/المعلم إعداد محتوى صف محلياً وتصدير ZIP خاص به؛ يستطيع كل طفل استيراد الحزمة على iPad وفتح PDF الدروس Offline، وحل الأنشطة والاختبارات مع حفظ التقدم والدرجات تحت هويته. يستطيع الوالد مراجعة تقارير كل طفل دون خلط بياناتهم، مع مزامنة آمنة عند توفر الخدمة.

**القرار المعماري المعتمد لهذا المسار:** التطبيق الحالي يظل محلياً أولاً؛ Room/SQLite تحفظ الفهرس والبيانات، وWorkspace يحفظ ملفات الدروس، وحزمة ZIP لكل صف توزع المحتوى إلى أجهزة الأبناء. أداء كل طفل يسجل محلياً بمعرف مستقل، وتُفصل مزامنته online عن حزمة المحتوى. يجب التحقق من التقنية الفعلية في المستودع قبل اعتماد أي توجيه تقني قديم في هذه الوثيقة.

# Educational content review — evidence-based audit contract

راجع المحتوى الحالي للدرس في ضوء مصدره وأهدافه ومفاهيمه ومخطط المهمة. المطلوب تقرير تدقيق، وليس إعادة كتابة المحتوى أو استبداله.

## مجالات التدقيق
- الدقة العلمية أو المعرفية وصحة المصطلحات والقوانين والوحدات.
- الاتساق مع الكتاب والصفحات والمفاهيم والأهداف.
- اكتمال العناصر المطلوبة في نوع المحتوى.
- صحة الأمثلة والحسابات والإجابات والعلاقات السببية.
- جودة اللغة ووضوح الشرح وملاءمته للصف.
- التكرار والتناقض والغموض والمعلومات غير المسندة.
- الالتزام بمخطط الاستجابة وقابلية العرض في التطبيق.

## توثيق كل ملاحظة
لكل مشكلة، حدد:
- رمزاً أو عنواناً موجزاً للمشكلة.
- موضعها في المحتوى الحالي.
- النص أو الدليل الذي استندت إليه.
- نوعها: خطأ factual/scientific، نقص، تناقض، غموض، ضعف تربوي، أو مخالفة للمخطط.
- شدتها: blocker أو major أو minor أو suggestion.
- سبب الحكم، مع التمييز بين خطأ مؤكد ومعلومة لا يمكن التحقق منها.
- التصحيح المقترح دون تطبيقه.

## قواعد الحكم
- لا تصف معلومة بأنها خاطئة لمجرد أنها غير موجودة في مقتطف المصدر؛ صنفها غير مدعومة أو تحتاج تحققاً إذا لم يتوفر الدليل الكافي.
- لا تخترع مرجعاً أو اقتباساً أو صفحة.
- لا تمنح درجة صحة رقمية كلية دون معيار واضح.
- لا تفترض أن غياب عنصر اختياري خطأ.
- لا تنفذ أي تعديل على المحتوى الأصلي؛ أخرج تقرير مراجعة منفصلاً.
- أخرج تقرير Markdown منظماً، مع جدول للملاحظات يتضمن النوع والموضع والدليل والشدة والسبب والتصحيح المقترح.
- اختم بحدود المراجعة وما تعذر التحقق منه. لا تخرج JSON.

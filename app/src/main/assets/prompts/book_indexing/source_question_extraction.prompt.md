# Source question extraction — verbatim preservation contract

استخرج الأسئلة والتمارين الموجودة فعلياً في صفحات الدرس. هذه المهمة توثيق حرفي للمصدر وليست توليداً أو تحسيناً أو إعادة صياغة.

## الأمانة للمصدر
- انقل نص السؤال كما يظهر، مع الحفاظ على ترتيب الأسئلة والفروع والترقيم داخل النص قدر الإمكان.
- انقل الخيارات كما وردت وبترتيبها، ولا تضف خيارات غير موجودة.
- احتفظ بالتعليمات المشتركة التي تنطبق على مجموعة أسئلة ضمن نص السؤال أو بنية العنصر دون إسقاطها.
- ميّز بين سؤال صريح ومهمة نشاط ومثال محلول؛ لا تحول المثال إلى سؤال.
- لا تصحح أخطاء الكتاب بصمت ولا تعِد صياغة السؤال لتحسينه.
- لا تخترع إجابة نموذجية. املأ correctAnswer فقط إذا كانت الإجابة ظاهرة أو مذكورة صراحة في المصدر؛ وإلا اتركها نصاً فارغاً.

## المصدر والمواضع
- اربط كل سؤال برقم الصفحة الفعلي عندما تكون بيانات الصفحة متاحة.
- لا تنشئ أرقام صفحات أو نصوصاً مفقودة.
- إذا تعذر قراءة جزء من السؤال أو خيار، لا تستكمله بالتخمين.

## الإخراج
- أخرج JSON صالحاً فقط مطابقاً لمخطط التطبيق، على شكل كائن يحتوي questions.
- كل عنصر يضم type عند إمكان تحديده، prompt بالنص الأصلي، options بالترتيب الأصلي، correctAnswer فقط إذا وردت صراحة، وsourcePages عند توفرها.
- استخدم معرفات الأنواع الداخلية عند وضوحها فقط: mcq, true_false, fill_blank, ordering, matching, short_answer. إذا لم يكن النوع واضحاً فاترك type فارغاً ودع التطبيق يستنتجه من بنية السؤال.
- لا تنشئ معرفات قاعدة البيانات أو حالة المراجعة أو نوع المصدر؛ التطبيق يحدد sourceType = BOOK_EXTRACTED.
- لا تضع مستوى صعوبة أو مفهوماً تعليمياً على أنه معلومة أصلية من الكتاب.

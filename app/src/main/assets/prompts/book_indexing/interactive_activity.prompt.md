# Interactive activity — declarative activity contract

أنشئ نشاطاً تعليمياً تفاعلياً قصيراً مرتبطاً بمفاهيم الدرس وأهدافه، والتزم حرفياً بمخطط JSON الذي يرسله التطبيق. هذه المهمة تنتج نشاط ممارسة، وليست بديلاً عن الشرح الكامل للدرس.

## التصميم التعليمي
- حدّد هدفاً قابلاً للملاحظة، ومفهوماً مستهدفاً لكل محطة أو خطوة.
- اجعل كل خطوة تتطلب من المتعلم إجراءً ذا معنى: ملاحظة، اختيار، تصنيف، ترتيب، مطابقة، أو تفسير.
- انتقل من الأسهل إلى الأصعب، ولا تستخدم التفاعل لمجرد الزخرفة.
- اجعل التغذية الراجعة تشرح سبب صحة الإجابة أو خطئها بلغة مناسبة للصف.
- استخدم أسئلة تحقق قصيرة مرتبطة بالمفهوم الذي تعرضه الخطوة.
- اجعل عناصر الترتيب والمطابقة مستندة إلى تسلسل أو علاقة صحيحة في الدرس.

## الأمان وصحة المحتوى
- أخرج JSON صالحاً فقط، دون Markdown أو JavaScript أو HTML أو تعليمات تنفيذية حرة.
- لا تضف حقولاً غير موجودة في المخطط، ولا تغيّر أسماء الحقول أو أنواعها.
- لا تضع كوداً أو روابط خارجية أو شيفرات قابلة للتنفيذ داخل النصوص.
- لا تخترع حقائق أو خطوات علمية أو إجابات غير مسندة إلى المصدر.
- لا تجعل نقطة التحقق جزءاً من بنك الأسئلة الرسمي؛ التطبيق يتعامل معها وفق مسار نقاط التحقق التفاعلية.
- تأكد من تطابق الإجابة مع أحد الخيارات عند اشتراط الخيارات، ومن عدم وجود أكثر من إجابة صحيحة غير مقصودة.

## قابلية الاستخدام
- استخدم نصوصاً قصيرة وواضحة، وتجنب ازدحام الشاشة.
- لا تفرض ترتيباً أو مطابقة إذا لم تكن مناسبة للمفهوم.
- إذا لم يكن نوع التفاعل مناسباً للدرس، استخدم المحطات ونقاط التحقق فقط ضمن ما يسمح به المخطط.
- راجع اتساق العنوان والهدف والخطوات والمفاهيم قبل إخراج النتيجة.

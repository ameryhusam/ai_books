# Interactive activity — indexer2 contract

أخرج JSON صالحاً فقط، دون Markdown أو JavaScript أو HTML حر.
العقد:
{
  "title": "string",
  "objective": "string",
  "steps": [{"title":"string","body":"string","checkpoint":{"question":"string","options":["string"],"answer":"string"}}],
  "ordering": ["string"],
  "matching": [{"left":"string","right":"string"}]
}
- يجب أن تكون كل خطوة قابلة لتنفيذ الطالب ومصاغة بإيجاز يناسب شاشة الهاتف المحمول.
- يجب أن يكون checkpoint.answer مطابقاً تماماً لأحد الخيارات.
- اجعل الترتيب والتوصيل مستندين إلى محتوى الدرس.
- لا تستخدم روابط أو شيفرات أو موارد خارجية.

# Lesson summary — indexer2 contract

أنشئ ملخصاً للمراجعة لا يضيف محتوى خارج المصدر.
- اذكر الفكرة المحورية ثم المفاهيم والقواعد والمصطلحات.
- استخدم نقاطاً قصيرة وجداول مقارنة عند وجود مقارنة حقيقية.
- حافظ على الوحدات والرموز والصيغ كما وردت.
- أرفق أرقام الصفحات عند توفرها.
- لا تحذف شرطاً أو استثناءً يغيّر معنى القاعدة.
